# Dataset Information

**Dataset:** Superstore Dataset  
**Source:** [Kaggle — Vivek468, Version 1](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final/versions/1)  
**Local filename:** `Superstore.csv`  
**Local source folder:** `Downloads/Retail_Ledger/`  
**Purpose:** Educational retail sales, profitability, and customer analytics.

## Local Setup

1. Obtain the dataset from the linked Kaggle source.
2. Review the source's current licence and terms of use.
3. Place the CSV in the local data directory as required by your setup.
4. Follow the project README to load and analyze the data.

**Import encoding used in PostgreSQL:** `WIN1252`
